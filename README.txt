TIMES TABLES TRAINER — INSTALLATION

This is an installable Progressive Web App (PWA). It works offline after installation and saves mistake history on the phone.

EASIEST FREE METHOD — GITHUB PAGES
1. On a computer, unzip times-tables-app.zip.
2. Create a free account at github.com if needed.
3. Create a new PUBLIC repository, for example: times-tables-trainer.
4. Upload ALL FOUR app files from the folder: index.html, manifest.json, sw.js, icon.svg.
5. In the repository open Settings > Pages.
6. Under Build and deployment choose "Deploy from a branch".
7. Select branch "main" and folder "/ (root)", then Save.
8. GitHub will show the website address after deployment (often within a few minutes).
9. Open that address in Chrome on your Android phone.
10. Chrome menu (three dots) > Add to Home screen / Install app > Install.
11. The Times Tables Trainer then appears like an app and works offline.

DATA
Mistake history is stored locally in the browser/app on that phone. Clearing Chrome site data can erase it.

APP LOGIC
- Full Trial includes every ordered combination from 2×2 through 12×12 (121 facts).
- Questions are shuffled.
- An incorrectly answered fact goes back into the current queue and repeats until answered correctly.
- All incorrect facts are recorded and displayed at the end.
- Mistakes Only uses the persistent saved-mistakes list.
- In Mistakes Only mode, a fact must be answered correctly on 3 separate appearances before it is removed from the saved list.
- A wrong answer resets that fact's mastery streak to 0, and it remains in practice.
- The Saved Mistakes screen shows progress toward mastery (0/3, 1/3, or 2/3).

VERSION 3 - GAME MODE
Added: 12 progressive stations, decreasing answer timer (15s to 5s), coins, stars, daily streak, shop rewards, and mastery-based mistake practice. A timeout counts as an incorrect answer and the fact returns later.
